# Module contract template

Record purpose; inputs and encodings; size/count/range limits; zero/exact/one-past
behavior; outputs; ownership and borrowed lifetimes; nullable arguments; invariants;
allocation/resource failure and partial I/O behavior; cleanup; concurrency model;
and independently testable acceptance properties before implementation. Enumerate
required units/questions and error-boundary tests. Publication/release readiness is
separate from environment qualification.
